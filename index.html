1. Fundamentos del sistema polar

El polo O es el origen. El eje polar es la semirrecta que parte de O hacia la derecha (equivale al eje x positivo). Un punto se describe con el par (r, θ):

  • r: distancia dirigida desde el polo.
  • θ: ángulo medido desde el eje polar; antihorario si θ > 0, horario si θ < 0.
Radio negativo (r < 0): se dibuja el rayo en dirección θ y el punto se coloca en el rayo opuesto (θ + π), a distancia |r|. Por eso (−r, θ) = (r, θ + π).
Ángulo negativo (θ < 0): se gira en sentido horario. Además, (r, θ) = (r, θ + 2πk): la representación no es única.

Línea punteada: rayo de dirección θ. Punto rojo: ubicación real. Cambia r a negativo y observa cómo el punto salta al lado opuesto.

2. El “puente” Cartesiano ↔ Polar

Deducción. Con el triángulo rectángulo de hipotenusa r y ángulo θ en el origen: cateto adyacente x = r cosθ y cateto opuesto y = r sinθ. Elevando al cuadrado y sumando:

x² + y² = r²cos²θ + r²sin²θ = r²(cos²θ + sin²θ) = r²

y / x = (r sinθ)/(r cosθ) = tanθ  (x ≠ 0)

x = r cosθ   y = r sinθ   r² = x² + y²   tanθ = y/x

Cuidado: tanθ = y/x no basta para θ; hay que revisar el cuadrante (por eso se usa atan2).

4. Aplicación a límites en dos variables

Para (x,y)→(0,0) con forma indeterminada 0/0, se sustituye x = r cosθ, y = r sinθ. Como √(x²+y²) = r, acercarse al origen equivale a r → 0⁺ para cualquier θ. Si el resultado tiende a un valor L independiente de θ (acotando con |cosθ|, |sinθ| ≤ 1), el límite existe y vale L; si depende de θ, el límite no existe.

Ejemplo resuelto

lím(x,y)→(0,0) x²y / (x²+y²)

  1. Sustituir: x²y = r³cos²θ sinθ y x²+y² = r².
  2. Simplificar (r ≠ 0): f = r·cos²θ·sinθ.
  3. Acotar: |f| ≤ r·1·1 = r → 0 cuando r → 0⁺, sin importar θ.
  4. Conclusión: el límite existe y es 0.

Contraejemplo: xy/(x²+y²)

f = r²cosθ sinθ / r² = cosθ sinθ = ½ sin2θ

Depende de θ (0 en θ=0, ½ en θ=45°), así que el límite no existe.
